# Computer & Web Help pamphlet

Updated for individuals, personal projects, and businesses. Recreated from the supplied screenshots, with the same cream, green, and terracotta palette.

The finished two-page PDF is in `output/pdf/eric-jones-computer-web-help.pdf`.

Print on US Letter paper in landscape at actual size, double-sided, with short-edge flipping. Page 1 is the outside (flap, back/contact, front cover); page 2 is the inside. Make one test print before printing a batch. The panels divide the sheet into equal thirds.

Edit the text and layout in `build_pamphlet.py`, then run it with Python and ReportLab installed. The script uses the Georgia and Arial fonts supplied with macOS.
